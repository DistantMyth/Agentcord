Welcome to Agentcord

Agentcord is a multi-user collaborative agent network fork of oh-my-pi. Connected users collaborate in a shared chatroom where each user commands a Queen agent and helper workers, overseen by the King agent.

Configure Agent Models

All Queen, King, and Helper agents can be configured to different models independently.

Escalate / Ask Question

Worker Agents can ask questions to ANY Queen agent. Queen Agents can ask questions to the King Agent.

Spawn Helper Worker Agent

Your Queen agent commands over helper worker agents for specific sub-tasks.
